# 🛰️ Satellite Image Classification

## 📌 Project Overview

Satellite Image Classification is a Machine Learning / Deep Learning project that classifies satellite images into different land-cover categories based on their visual features.

The project aims to identify different geographical areas such as buildings, forests, water bodies, agricultural land, and other landscapes using image classification techniques.

## 🎯 Objectives

- Classify satellite images into different categories.
- Analyze geographical and land-cover patterns.
- Apply image preprocessing and classification techniques.
- Build a model that can predict the category of unseen satellite images.

## 🛠️ Technologies Used

- Pandas

## ⚙️ Project Workflow

1. Collect the satellite image dataset.
2. Load and explore the images.
3. Preprocess and resize the images.
4. Split the dataset into training and testing sets.
5. Train the classification model.
6. Evaluate model performance.
7. Predict classes for new satellite images.

## 🚀 Installation and Execution

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the project folder**

```bash
cd Satellite-Image-Classification
```

**Step 3: Install dependencies**

```bash
pip install -r requirements.txt
```

**Step 4: Run the Jupyter Notebook**

```bash

```

Open the satellite image classification notebook and execute the cells.
